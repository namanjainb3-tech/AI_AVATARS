# Pipeline Flow

1. User uploads image
2. User uploads voice sample
3. User enters script
4. Backend creates job
5. Worker detects job
6. FishSpeech clones voice
7. SeedVC enhances voice
8. InsightFace aligns face
9. GFPGAN enhances image
10. LivePortrait animates image
11. MuseTalk performs lip sync
12. CodeFormer enhances video
13. Final video generated
